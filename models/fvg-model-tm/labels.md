# Labels

The FVG Model provides customizable labels on HTF candles to help you quickly identify timeframe context and directional bias at a glance.

### HTF Candle Labels

Labels are displayed on each reconstructed HTF candle drawn on your LTF chart. They typically show the HTF timeframe identifier (e.g., "1H", "4H", "1D") and directional context.

* **Labels**: Master toggle to show or hide all HTF candle labels.
* **Label Size**: Control the text size of the labels. Options include Tiny, Small, Normal, Large, Huge, and Auto.
* **Label Color**: Set the color of the label text (default: gray).

### TP Labels (Standard Deviation)

When Standard Deviation projections are active, labels can be optionally displayed on the take-profit projection lines, clearly marking each target level.

* **Show TP Labels**: Toggle the visibility of take-profit labels on the projection lines.
* **Label Size**: Independently control the text size for TP labels, separate from the HTF candle labels.
